# План самостоятельной подготовки
## Назначение проекта
Консольная программа на Python, которая помогает студенту спланировать самостоятельную подготовку к занятиям, вычисляет суммарное время подготовки и долю достижения цели (10 часов), выводит итоговый отчет, построчную таблицу накопления часов по дням и позволяет при необходимости составить новый план.

## Вариант
**Вариант 3.** План самостоятельной подготовки.

## Используемые темы Python
- Ввод и вывод данных (`input()`, `print()`) и преобразование типов (`str`, `int`, `float`, `bool`).
- Арифметические операторы, операторы сравнения и логические выражения с `and`, `or`, `not`.
- Условные конструкции `if–elif–else`.
- Цикл `for` с функцией `range()` для пошагового расчета накопленного времени.
- Циклы `while` для проверки корректности вводимых данных и повторного запуска расчета.
- Пользовательские функции с параметрами, строками документирования и возвратом значений через `return`.
- Форматирование вывода с помощью `f`-строк (выравнивание по ширине, точность дробных чисел, формат `.1%` для долей, ведущие нули `:02d`).

## Описание глобальной константы и локальных переменных
- TARGET_HOURS (float) — глобальная константа уровня модуля, равная 10.0 (целевое количество часов подготовки).
- name (str) — локальная переменная в функции read_student_name() для хранения введенного имени студента после очистки пробелов.
- days (int) — локальная переменная с количеством дней подготовки (от 1 до 7).
- hours (float) — локальная переменная в функции read_daily_hours() для проверки и возврата ежедневного времени занятий.
- total_hours (float) — локальная переменная с суммарным временем подготовки за все дни (days * daily_hours).
- target_hours (float) — локальный параметр функций get_goal_status() и print_plan_report(), принимающий целевое значение часов.
- is_exact_target (bool) — локальная переменная в get_goal_status(), показывающая, равно ли суммарное время целевому значению.
- status (str) — локальная переменная с итоговым выводом («Времени недостаточно», «Цель достигнута» или «Есть дополнительное время»).
- student_name (str) — локальная переменная с именем студента в основном сценарии и отчете.
- daily_hours (float) — локальная переменная с ежедневным временем занятий в часах (от 0 до 12).
- goal_share (float) — локальная переменная с долей достижения цели (total_hours / TARGET_HOURS).
- line (str) — локальная переменная с разделительной линией шириной 60 символов в print_plan_report().
- accumulated_hours (float) — локальная переменная-накопитель часов по дням в цикле for.
- day_share (float) — локальная переменная с долей достижения цели на конкретный день.
- answer (str) — локальная переменная с обработанным (.strip().lower()) ответом пользователя о повторном расчете.
